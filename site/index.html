Cobble

Pebble Templates for VS Code

“What is best in template coding? To crush your syntax errors, see them driven before you, and to hear the lamentations of the improperly closed Pebble tags!”

Install from the Marketplace Source on GitHub

Every stone in place

Language support for Pebble 4.x, in .html files and in .peb and .pebble files. A language server does the work, so it stays responsive in large templates.

What it lays down

Highlighting

The complete Pebble 4.1 syntax: interpolation, whitespace control, verbatim, and every built-in tag, filter, function and test. Pebble inside attribute values is highlighted too.

IntelliSense

Tags with the matching end tag first, filters, functions, tests, variables in scope, macros, block names and template names. Hover documentation and signature help for everything built in.

Diagnostics and quick fixes

Unclosed delimiters and tags, mismatched end tags, syntax errors, unknown filters and missing templates, with fixes to insert the end tag or create the template.

Navigation

Go to definition, find references and rename across the whole extends hierarchy. CodeLens shows which templates extend a layout and where each block is overridden.

Java and Kotlin awareness

Reads your Spring, Ktor and Javalin code to learn what each template receives: typed completion for model attributes and bean properties, and the filters, functions and tests your extensions register.

Datastar and HTMX

No completions or diagnostics outside Pebble syntax, so the Datastar extension and HTMX tooling keep working as before. In .peb files, Cobble brings the Datastar highlighting along.

Lay the first stone

From the command line, or search for Cobble in the Extensions view:

code --install-extension MarkusAugust.pebble-support

Settings, snippets and the full list of what Cobble reads from your Java and Kotlin code are in the README.
